# Customer Churn Analysis — Databel Telecom (Power BI)

## Overview

This project analyzes customer churn for Databel, a fictional telecom company, using Power BI.
The goal is not just to measure churn, but to understand the drivers behind it and surface
actionable insights for reducing it. The analysis covers churn rate calculation, pattern
investigation across customer segments, and dashboard-style reporting for stakeholders.


## Project Structure

### 1. Exploratory Analysis
- Defined and calculated the churn rate using DAX measures and calculated columns
- Investigated primary churn reasons and categories
- Used map visuals to identify geographic patterns in churn behavior

### 2. Investigating Churn Patterns
- Analyzed churn across demographic segments including age groups
- Examined the impact of plan type (unlimited vs. non-unlimited) on churn
- Investigated international call behavior as a churn driver
- Assessed the relationship between contract type and churn likelihood

### 3. Visualizing the Analysis
- Built dashboard-style report pages suitable for stakeholder presentation
- Arranged visuals into a coherent narrative flow across multiple report pages

---

## Tools & Techniques

- **Power BI Desktop** — report development and data modeling
- **DAX** — measures and calculated columns for churn metrics
- **Power BI Visuals** — bar charts, maps, matrix tables, and KPI cards

---

## Key Questions Addressed

- What is Databel's overall churn rate?
- Which customer segments churn at the highest rates?
- Do plan type, contract type, or call behavior influence churn?
- What can Databel do to reduce churn?
